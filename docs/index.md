# lmLite

A Python bridge to Transformers.js for JupyterLite: run language models, embeddings, vision, speech and bare ONNX models entirely in your browser.

Try it without installing anything: [xeus-python](https://decitre.github.io/lmlite/xeus/lab/?path=ch01_demo.ipynb) (recommended) or [Pyodide](https://decitre.github.io/lmlite/pyodide/lab/?path=ch01_demo.ipynb). The [tutorials](tutorials/index.md) are notebooks; the [guides](guides/index.md) solve one task each; the [reference](reference/index.md) lists exact options; the [explanation](explanation/index.md) says why things work as they do.
